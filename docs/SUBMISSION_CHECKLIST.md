# Submission evidence

Use the [acceptance checklist](ACCEPTANCE.md) to record capture, signed webhook delivery, reproducible setup, public source, video and submission confirmation. Check actual public access to the repository and YouTube video before submitting. The local build and an MIT license are available. Entrant ownership and third-party permissions require the entrant's review.

See [rules and sponsor decisions](RULES_AND_PRIZES.md). Empty checkboxes are release blockers, not implied passes. Record the date, tester and evidence beside each completed item. Keep secrets out of this file.

- [ ] Third-party notices reviewed, secrets excluded from source and history.

- [ ] AG Grid sponsor choice and demonstrable contribution included.
